你準備建立哪一種 Agent 表單？

可以連到已有 Agent 的精確身份，也可以先建立一張由 Form Studio 管理的獨立表單。

改裝 · 已有 agent

選擇已有 Poffices agent

目前接口只支援用數字 ID 精確查找。這一步讀取名稱和身份狀態，用來確認表單主人；不讀取 Agent 內部欄位，也不修改 Poffices。

在哪裡找到 Agent ID？

打開 Poffices 中該 Agent 的詳情或網址，複製其中的數字 ID。Form Studio 目前不提供名稱搜尋，以免選錯同名 Agent。

只建立 Form Studio 本地頁面欄位、發布版本和提交記錄都留在本地，不修改 Poffices 的 agent 配置或官方入口。

Form Studio 本地建立

新建獨立的 Agent 表單

名稱同時用作 Agent 名稱和填寫頁標題。它可以獨立設計、發布和持續接收提交，目前不會建立、連接或修改 Poffices Agent。

建立後：系統會儲存一個本地頁面身份，重新命名和重新啟動都不會改變頁面歸屬。

不會發生：它不能改綁成已有 agent；需要複用時應複製欄位設計，不移動原頁面和提交記錄。
