改裝 · 已有 agent

選擇已有 Poffices agent

目前接口只支援用數字 ID 精確查找。這一步讀取名稱和身份狀態，用來確認頁面主人；不讀取 agent 內部欄位，也不修改 Poffices。

只建立 Form Studio 本地頁面欄位、發布版本和提交記錄都留在本地，不修改 Poffices 的 agent 配置或官方入口。

新生 · Form Studio 本地建立

建立新的 agent form

它可以獨立設計、發布和持續接收提交。目前不會建立、連接或修改 Poffices agent。

建立後：系統會儲存一個本地頁面身份，重新命名和重新啟動都不會改變頁面歸屬。

不會發生：它不能改綁成已有 agent；需要複用時應複製欄位設計，不移動原頁面和提交記錄。
